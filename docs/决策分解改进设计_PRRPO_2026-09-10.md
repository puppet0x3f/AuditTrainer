### 1.2 要学习的能力

1. 是否直接实现当前职责，还是创建子职责。

## 4. 策略表示：模式先决策，正文条件生成

### 4.1 状态与动作

宿主状态记为 \(x\)，模型可见 observation 记为 \(o=O(x)\)。候选比较固定完整宿主状态，策略只接收现有公开输入。后文为简洁把一个决策状态记为 \(s=(x,o)\)。

\[
a=(g,z),\qquad
g\in\{0:\mathrm{ATOMIC},1:\mathrm{SPLIT}\}
\]

\[
\pi_\theta(a\mid o)
=
p_\theta(g\mid o)\,q_\theta(z\mid o,g)
\]

第一版仅训练 `phase=NEW` 的初始计划。授权修复中的 `base_plan_version>0` 计划由固定修复策略处理，不与初始细化混作同类动作。

模式只在 `allowed_plan_modes` 范围内选择。只允许 ATOMIC 的深度/节点边界上，模式概率确定为 1，不生成非法 SPLIT 候选，也不把宿主强制停止当成学会停止的证据。

### 4.2 模式分布的具体定义

当前自由 JSON 生成及排序后的 SFT target，并不保证 mode 出现在 children 之前。新设计需要明确改变规划生成表示；不能从已经生成的完整计划中事后截出 mode，声称获得了独立的模式策略。

采用同一 Qwen 的二候选序列评分，无需增加分类头：

1. 在公开规划 prompt 后放置固定 JSON 前缀，终止在 mode 值开始之前。
2. 分别 teacher-force 合法模式的 token 序列 \(e_0,e_1\)，计算序列对数分数：
   \[
   \ell_\theta(g\mid o)
   =\sum_t\log P_\theta(e_{g,t}\mid h(o),e_{g,<t})
   \]
3. 以合法候选上的归一化分布定义模式概率：
   \[
   p_\theta(g\mid o)
   =\frac{\exp\ell_\theta(g\mid o)}
   {\sum_{g'\in\mathcal G(o)}\exp\ell_\theta(g'\mid o)}
   \]
4. 自然运行从该分布采样一次模式；训练的分层比较则枚举两个模式。

这是新规划策略自身的概率定义，不等于旧自由 JSON 模型输出该 mode 的边缘概率。

已用本地 Qwen3 tokenizer 核对：裸字符串 `ATOMIC` 为 `[828, 51793]`，`SPLIT` 为 `[50, 51597]`，均不是单 token。实现应以实际前缀和保存的 token 边界为准，计算完整候选序列分数及归一化概率，不能只取某个“模式 token”的 logit。

### 4.3 正文与宿主组装

当 \(g=0\) 时，使用确定性原子计划：

- `base_plan_version=0`，`ticket_id=null`；
- `children=[]`，`dataflow=[]`；
- incoming ensures 中每个 ID 映射到 `["self"]`；
- `retained_responsibilities` 沿用 incoming contract 的 `owns`，与现有 `atomic()` 一致。

这是宿主根据完整当前契约构造的 payload；模式选择仍由模型作出。该分支 \(q(z\mid o,0)=1\)，没有正文策略梯度。

当 \(g=1\) 时，固定 mode 与版本前缀，让模型生成 children、obligation_map、retained_responsibilities、dataflow 及 JSON 结束部分，作为一个完整联合正文。示意：

~~~text
固定前缀：{"action":"plan","args":{"base_plan_version":0,"mode":"SPLIT",
模型正文："children":[...],"obligation_map":{...},
          "retained_responsibilities":[...],"dataflow":[...],"ticket_id":null}}
~~~

宿主只固定约定前缀和原子模板，不能替模型补完 SPLIT 的责任分配。重复覆盖 mode/version 等前缀字段、缺字段、非法 JSON、超长输出保留为无效候选，不通过字符串修补变成成功示范。

训练记录同时保留：

- 两种模式的评分输入、候选 token IDs 和旧归一化概率；
- 正文的原始输入 IDs、原始输出 IDs、旧逐 token log-probability；
- prompt、固定前缀、模式评分位置、正文与 padding 的范围；
- 实际提交给 runtime 的完整 action，以及各部分由模型/宿主产生的来源。

旧概率必须对应真正采样的原始 token。解析后的 JSON 可以规范化存储，但不能重新排序、重新分词后沿用原概率。

### 4.4 表示适配与采样一致性

先使用现有 TRAIN 计划样本进行一次小规模表示适配：mode 用归一化二元 CE，SPLIT 正文用条件 CE；全部新方法从同一个适配后的 checkpoint 开始。此步骤是 SFT，不计作 RL 收益。适配前后各保留一次同环境评测，防止把格式和原子模板改进计入算法收益。

RL 规划采样建议从 `temperature=1.0, top_p=1.0, top_k=0` 起步。当前主配置的 temperature 0.7 / top-p 0.8 / top-k 20 不可直接采样后配上未经处理的原始 softmax 概率。若以后改变采样分布，新旧概率必须采用同一变换。

RL 采样、旧概率重算和更新计算关闭 dropout，梯度仍开启；避免仅因 dropout 导致更新前概率比率不为 1。原 SFT dropout 设置不直接照搬进这条 RL 路径。

## 5. 责任保持与长期回报

### 5.1 保持外部契约，允许内部共同履约

incoming contract 的签名、输入前提、输出要求、frame 和版本继续由宿主固定。父节点可以下放责任，但不能借分解删除原义务或缩小外部任务。

新实验增加的结构检查限于具体可判定事项：每个 incoming obligation ID 都有非空映射；引用者为 self 或已声明 child；现有版本、child 标识和 dataflow 引用检查继续生效。多个节点共同满足一个整体 obligation 是允许的。

这些检查不证明职责语义完整、不证明 parent 真正消费 child，也不禁止所有形式的共同实现。语义结论仍依赖绑定到具体契约和产物的执行/审查证据。无证据的项目保留 UNKNOWN。

有限检查通过新实验配置接入注册路径，不能把失败候选从采样池中删除。原协议的历史 trace 与实验不回写成新规则下的结果。

### 5.2 根任务奖励

采用新方案的终局目标：

\[
R(\tau)=(1-v_\tau)y_\tau-\lambda c_\tau-\mu v_\tau,
\qquad \gamma=1.
\]

- \(y_\tau\)：复用现有 evaluator 的终局产物选择口径，在产物冻结后通过 TRAIN 根任务可信私有评分为 1。NO_PROGRAM、FAIL、UNKNOWN 为 0；正常提交状态另报。
- \(v_\tau\)：最终生效产物或确已发生的执行行为中，有可靠、当前有效证据支持的责任违规。
- \(c_\tau\in[0,1]\)：正常执行这一条方案的资源成本代理，含规划、实现、在线验证与修复。
- 评分基础设施 ERROR 不作为模型失败奖励；保留记录并处理后重新完成对应比较。无法完成的比较不产生优势。

初始成本代理使用现有预算计数：

\[
c_\tau=
0.7\min(T_\tau/B_T,1)
+0.2\min(N_\tau/B_N,1)
+0.1\min(V_\tau/B_V,1).
\]

\(T,N,V\) 分别为输入输出 token、业务策略决策、在线验证调用；分母为预先固定的根预算。执行用例数、执行秒数、物理模型前向与离线评分成本另外如实报告。v1 不把受机器负载影响的 wall time 直接用作奖励。

建议零更新诊断先用 \(\lambda=0,\mu=0.2\)，同时保存成本以便分析。正式实验建议从 \(\lambda=0.05,\mu=0.2\) 起步，在 TRAIN 诊断后一次确定，并对所有对照一致使用。正文中的数值是待实施的初值，不是已调优参数。

### 5.3 违规证据的适用范围

可直接使用的证据包括当前 verifier 确认的禁止输入修改、未批准依赖调用等。计划责任遗漏或绕过 child 只有在相应审查规则确实适用时才能进入 \(v_\tau\)。

不能直接执行：

~~~python
v = int(runtime_result["responsibility_status"] == "VIOLATION")
~~~

当前 runtime 可能因为 child 被 reject 就产生该状态；它不等价于独立证明了最终程序的语义责任错误。被宿主阻止且后续纠正的非法尝试，也不应一概当成最终仍存在的责任违规。已修复旧版本的违规不能污染当前产物标签；其真实消耗仍计入成本。

UNKNOWN 对应“未能确认”，不直接罚分，也不计作已验证履约。分别报告功能通过、证据支持的责任通过、已确认违规与 UNKNOWN 比例。新契约缺少适用 LOCAL suite 时沿用 UNKNOWN，不要求为每个自然生成契约建立新 oracle；根测试仍可评价最终功能。

### 5.4 修复与评分隔离

初始规划训练先使用无修复环境，其 \(R_{\rm ref}=\varnothing\)，明确只检验执行与组合的长期效用。接入 A7 后，使用同一个固定修复器和有界控制规则评价修复后的根结果。

修复只通过更高的终局成功或更低成本体现价值，不额外奖励“发生修复”或“修复次数”。中间节点的价值估计必须继续完成父组合和根任务；局部 PASS 不能提前结束估值。

沿用 [数据分区规则](/home/lc/AuditTrainer/data/manifests/splits.yaml)：TRAIN 私有评分只在训练离线侧生成回报，不进入 observation，不触发该候选续跑中的修复选择。VALIDATION、DEV 和 SEALED 的评分都不进入 RL 更新。所有分支和子节点继承 root 的分区。

## 6. 分层候选与双层优势

### 6.1 固定比较环境

每轮采样固定：

- \(\bar\theta\)：本轮旧规划策略，负责各层后续初始计划；
- \(E_{\rm ref}\)：冻结的实现与消费/组合策略；
- \(R_{\rm ref}\)：该实验条件下冻结的修复策略，或明确关闭；
- task、incoming contract、决策前文件与预算、在线可见 suites。

\[
Q(s,g,z)
=\mathbb E[R(\tau)\mid x,g,z,\pi_{\bar\theta},E_{\rm ref},R_{\rm ref}].
\]

即使本轮只更新根决策，也不把所有 child 强制为 ATOMIC。那种设置只能作为“一层规划”的额外诊断。

### 6.2 候选采样与回报估计

对同时允许两种模式的状态：

- 构造一个规范原子计划，续跑 \(M=2\) 次，均值记为 \(\hat Q_{\rm A}\)。
- 独立、有放回地采样 \(K=3\) 个 SPLIT 正文。
- 每个正文固定后续跑 \(M=2\) 次，均值记为 \(\hat Q_i\)。

\[
\hat Q_{\rm S}=\frac1K\sum_{i=1}^K\hat Q_i.
\]

重复采到相同正文也保留其样本次数。不能通过去重或删除无效候选改变条件分布。非法计划、截断和协议重试耗尽属于采样结果；初次拒绝后按既有重试上限续跑，由固定后续策略处理，其终局回报保留为该初始选择的结果。

条件采样保证能够观察 SPLIT 分布，但不保证正文可执行。如果整个条件分布都不可执行，先用少量 TRAIN 执行支持示范作一次共同的 SFT 补充；不增加 child 数量奖励，也不为同一候选无限重试。

### 6.3 模式优势

令 \(p=p_{\bar\theta}(\mathrm{SPLIT}\mid o)\)，则：

\[
\hat V=(1-p)\hat Q_{\rm A}+p\hat Q_{\rm S},
\]

\[
A^{\rm mode}_{\rm S}=(1-p)(\hat Q_{\rm S}-\hat Q_{\rm A}),\qquad
A^{\rm mode}_{\rm A}=-p(\hat Q_{\rm S}-\hat Q_{\rm A}).
\]

模式学习依据当前条件策略的平均分解质量。最大候选值只用于诊断潜力，不能代替 \(\hat Q_{\rm S}\)。

### 6.4 正文优势

\[
A^{\rm body}_i
=
\hat Q_i-\frac1{K-1}\sum_{j\ne i}\hat Q_j,\qquad K\ge2.
\]

该优势作用于整个 SPLIT 责任分配正文，暂不拆到单个 child 或契约字段。它使同一状态中相对好的拆法获得正向信号，即使当前 SPLIT 平均价值仍低于 ATOMIC。

假设数据示例，非项目实验结果：

| 选择 | 长期回报估计 |
| --- | ---: |
| ATOMIC | 0.70 |
| SPLIT A | 0.85 |
| SPLIT B | 0.50 |
| SPLIT C | 0.45 |

若 \(p=0.4\)，则 \(\hat Q_{\rm S}=0.60,\hat V=0.66\)，模式优势分别为 ATOMIC \(+0.04\)、SPLIT \(-0.06\)，但正文 A 的优势为 \(+0.375\)。训练可以降低当前整体分解倾向，同时提高生成 A 类分配的概率。

### 6.5 概率权重与更新目标

在旧策略处，局部策略梯度的目标结构为：

\[
g_s=
\sum_{g\in\{\mathrm A,\mathrm S\}}
p_{\bar\theta}(g\mid o)A^{\rm mode}_{g}
\nabla_\theta\log p_\theta(g\mid o)
+
\frac{p}{K}\sum_i A^{\rm body}_i
\nabla_\theta\log q_\theta(z_i\mid o,\mathrm S).
\]

分层枚举模式不等于从完整策略中均匀采样。模式项保留各自的旧概率，正文项保留 \(p/K\)；不能把四条候选简单摊平、各赋四分之一权重。所有旧概率、回报与优势在更新中 detach。

定义裁剪函数：

\[
\Phi(r,A)=\min(rA,\operatorname{clip}(r,1-\epsilon,1+\epsilon)A).
\]

模式采用完整归一化模式概率比率 \(r_g=p_\theta(g\mid o)/p_{\bar\theta}(g\mid o)\)。正文用相同原始前缀下的 token 比率 \(r_{i,t}\)。实现目标：

\[
J_{\rm mode}=\sum_g p_{\bar\theta}(g\mid o)\Phi(r_g,A^{\rm mode}_g),
\]

\[
J_{\rm body}=\frac pK\sum_i\sum_{t\in z_i}\Phi(r_{i,t},A^{\rm body}_i),
\]

\[
J=J_{\rm mode}+J_{\rm body}-\beta L_{\rm KL}-\eta L_{\rm SFT}.
\]

模式按二元分布计算，不能给两个 mode token 各自套正文裁剪代替模式概率比率。正文求 token 和，再按候选数和状态数平均；不直接复用当前 SFT 的逐样本长度平均，从而悄悄改变模式与正文的相对权重。若需要数值缩放，对两项施加共同常数。

KL 使用固定 SFT 参考：模式计算二元 KL；正文在旧策略采样前缀上计算当前/参考 token 分布 KL。该正文约束是采样前缀上的代理约束，token 裁剪也是实用代理目标，不声称等同于精确序列重要性采样或获得全局最优保证。

少量 SFT 保持项使用 TRAIN 协议与已有计划示范，帮助防止格式退化。RL 各组共享其比例和系数。策略 KL 与 SFT 保持不替代执行回报。

本设计阶段已对有限离散例子枚举 \(3^3\) 个条件样本组合：带 \(p/K\) 的正文留一估计与解析梯度一致，示例正文梯度为 \((0.033333,-0.013333,-0.020000)\)。这仅核对局部公式与概率权重，不是训练效果验证。

## 7. 固定角色与分支续跑

### 7.1 路由规则

| 状态/动作 | 负责策略 |
| --- | --- |
| 初始 NEW 计划，根和子节点相同 | 当前规划策略；采样批次中为 \(\pi_{\bar\theta}\) |
| IMPLEMENT、常规 RESOLVE_CHILD | 固定 \(E_{\rm ref}\) |
| 常规 verify、完成提交 | 与对照共享的确定性协议控制 |
| 启用修复后的可见失败处理、授权 repair/plan revision | 固定 \(R_{\rm ref}\) 与既有 ticket 规则 |
| 终局私有评分 | 宿主离线 evaluator |

只对 plan token 计算 loss 不能保证同一模型的其他输出不变。隔离阶段必须真正切换到冻结权重。

可复用一个冻结 NF4 底座，分别加载当前规划、轮次旧规划、固定执行和 SFT 参考的 LoRA 权重，按角色串行切换；所有非当前规划权重排除出 optimizer。沿用现有量化与磁盘回接能力，无需为本次设计引入分布式 agent 平台。

现有 BaseExecutor 的禁用 adapter 方法只对应公开底座，不能用它冒充冻结的 F01。采用 F01 时要切换到其独立固定 adapter。每个分支的随机种子、角色调用计数与模式必须独立恢复；当前 `BaseExecutor.calls` 的全局累增方式不能跨候选直接沿用。

### 7.2 根状态最小实现

根版本不依赖通用恢复接口：

1. 从同一个 TRAIN task、root contract、初始预算创建候选运行目录。
2. 强制注入本次选定的完整首个计划。
3. 后续使用固定本轮规划器及角色路由完成整条轨迹。
4. 冻结首个/终局产物，再做训练离线评分。

所有候选从同样的决策前状态开始，并扣除该方案正常部署所需的计划成本。强制注入不是免费动作，也不能标成脚本计划而忽略原先的模型开销。

### 7.3 中间状态快照

递归阶段只在动作执行前的稳定 NEW 状态分叉，v1 不从正在进行的 ticket/subtree revision 事务中分叉。

快照需要保存足以续跑的最小运行数据：

- 所有 NodeExecution 的 node、plan、artifact、children、consumptions、返回/修复请求、错误计数和反馈；
- active node、stack、stop 状态、完整已用预算；
- 截止该时刻的 plans、artifacts、evidence 等实际文件；
- 已启用修复时的管理器状态及其路径引用；
- trace 游标、在线 suite/沙箱设置、策略角色身份和随机/调用计数。

不复制模型对象，不把私有评分器放入在线 runtime。分支有独立目录、ArtifactStore、TraceWriter 与路径绑定。第一版使用专用内存快照加文件复制即可，不增加跨版本通用序列化或恢复系统。

[Runtime.step](/home/lc/AuditTrainer/src/audittrainer/runtime.py:525) 在调用 policy 之前增加 policy_calls。因此分叉点应放在该次扣费之前；若选择别的位置，必须明确避免漏扣或重复扣费。保存的 observation 应与自然执行该动作时的公开输入一致，不能混入未来反馈或另一个分支的 artifact。

候选从这一状态继续执行到根任务终止，完整重跑后缀。此时不实现依赖图缓存、局部因果切片或只重算一小段消费者。后续只有实际成本证据表明值得优化时，再考虑责任边界下的局部重放。

### 7.4 重复、预算与成本

每个候选的两次续跑使用独立的固定种子。候选间可以使用相同的两组种子减少外部差异，但不同结构的模型调用序列会不同，不能据此宣称实现了完全相同的执行噪声。

区分两类账：

- **候选的正常执行成本**：这一计划在普通单分支运行中所需的规划、实现、验证和修复成本，用于 \(c_\tau\) 与根预算。
- **训练实际计算成本**：所有候选、重复、自然状态采集、模式评分和离线验证的真实总开销，用于公平比较训练效率。

门控对两种模式的评分是正常新策略的一部分。它的实际 token 处理量及模型前向也应计入，不能把规范 ATOMIC 当成零推理。policy_calls 仍表示完整业务决策次数，物理模型前向次数另报。

模式或正文被缓存用于多次续跑时，每条候选价值仍按正常执行逻辑计费；缓存仅减少训练实际开销。不能因训练时缓存命中而提高计划的奖励。当前已消耗的前缀预算不因分支而返还。

## 8. 从根计划扩展到递归策略

### 8.1 自然状态采集

每轮先冻结 \(\bar\theta\)，用自然模式采样运行 TRAIN 任务。递归阶段从这些真实轨迹中选取根起始状态和至多一个后续可学习规划状态，包括中间节点。

若共有 \(n\) 个符合条件的后续状态，从中均匀选择一个，保存纳入概率 \(\rho=1/n\)。希望估计这些决策的梯度和时，对该记录使用 \(1/\rho=n\) 的权重；也可明确采用课程重加权目标，但不能把未校正采样写成无偏的全轨迹梯度。

无 SPLIT 支持的宿主强制边界不产生模式梯度。若自然轨迹没有中间节点，根训练仍可进行；条件探索产生的中间状态可以作为单列的课程池，不能未经说明混入自然 on-policy 状态池。

各方法更新后策略分布会分化，不能永久共用另一方法采到的状态和动作而仍声称 on-policy。相同旧策略阶段可以共享候选批次作更新对照；持续在线训练使用各自采样，并匹配总计算预算。

### 8.2 递归深度与粒度

默认沿用现有 max_depth=2，即 root 深度 0、最多到孙节点；max_nodes=7、max_children=3。根更新阶段的后续规划也允许这两层细化，避免把“本层暂时无收益”变成进一步探索的禁令。

PR1C 的可执行性课程另行固定 max_depth=1，使叶节点直接实现，先建立根责任分配的价值信号。
该课程的配置与结果独立保存；PR2 的递归状态训练仍按本节的递归目标推进。

只有训练任务确实需要更深规划时再调整深度预算，并对同轮所有对照一致修改。课程扩展的是可处理任务与可访问状态，而不是要求平均深度随训练增长。

不同执行器的能力并没有作为一个显式字段出现在当前 observation 中。因此，固定 E_ref 训练出的策略可以被称为“相对于该执行器优化”，不能直接声称它能够识别并适应任意新执行器。预算适应可以通过已有 budget_remaining 输入检验；执行器变化先作为独立迁移实验。

## 10. 训练流程

以下是目标流程伪代码，所列新增函数尚待实现：

~~~python
theta = adapt_plan_representation(existing_sft_adapter, train_plan_examples)
reference = freeze_adapter(theta)
executor = freeze_adapter(f01_adapter)

for iteration in range(fixed_iteration_budget):
    old = freeze_adapter(theta)
    records = []

    for task in sample_train_roots():
        states = collect_states(
            task, planner=old, executor=executor, repairer=fixed_repairer,
            root_only=stage_is_root_training,
            max_additional_states=1,
        )
        for snapshot, observation, inclusion_prob in states:
            if "SPLIT" not in observation["allowed_plan_modes"]:
                continue

            mode_probs = old.score_modes(observation)
            atomic = canonical_atomic(observation["incoming_contract"])
            splits = old.sample_split_bodies(observation, k=3)
            # 保留重复、无效与截断候选，保存其原始概率。

            outcomes = run_all_candidates_to_root(
                snapshot, [atomic] + splits, repetitions=2,
                continuation_planner=old,
                executor=executor, repairer=fixed_repairer,
            )
            records.append(build_record(
                mode_probs, splits, outcomes, inclusion_prob,
            ))

    usable = complete_groups_without_infrastructure_errors(records)
    advantages = two_level_advantages(usable)
    theta = update_planner(
        theta, old_log_probs=usable, advantages=advantages,
        reference=reference, sft_examples=train_protocol_examples,
    )
    save_adapter_and_training_report(theta)
~~~

每轮先完成采样与旧概率，再更新。首版每批只做有限更新，随后刷新 old planner；不把所有历史 JSONL 当作可无限重复的 on-policy 数据。

不需要增加 critic 或自然语言 PRM。当前主要成本来自续跑，先用真实结果确认双层信用是否有价值，再决定是否值得用学习到的价值估计器降低采样开销。

PR0 的候选续跑数为 \(50\times4\times2=400\)。这不包含表示适配、自然轨迹采集、模式评分与离线验证的附加成本；正式报告分别计数。先在少量任务上验证一次端到端流程即可，随后完成固定规模，不反复增加烟雾测试。

两次续跑只能用于发现信号，不能据此给单个计划下稳定价值结论。PR0 同时查看：

- SPLIT 格式/注册与可执行比例；
- 有功能回报差异的状态比例及模式概率是否接近饱和；
- 模式差值 Q_S−Q_A、正文候选间差异及续跑波动；
- planner、executor、组合与基础设施错误的实际来源；
- 候选生成、续跑和验证成本。

若格式支持不足，允许一次共同的 TRAIN SFT 补充；若在合适训练任务上仍无回报差异，应报告信号不足及其原因，结束该轮更新尝试。不能用结构数量奖励制造差异。若差异已存在，就开展更新，不等待所有计划或执行器变得完美。

PR1/PR2 的正式迭代预算根据 PR0 实测成本一次确定，各方法使用相同总计算预算与固定报告时点；不把原 SFT 的 140 个更新步数直接当作等价 RL 预算。

PR0/PR1 可以先于完整 A7 收益实验推进；PR2 中“有修复”的科学结论依赖固定修复环境接通。原 A7/A8 的阶段编号和完成记录不被本文重写。PR3 首先是回接评测，不把它写成已完成所有角色的联合 RL；是否需要联合更新由迁移结果决定。

## 12. 核心实验与判断标准

### 12.1 五组对照

全部新组使用共同的规划表示适配 checkpoint、相同任务划分、合法动作、检查规则、执行器、预算和训练目标。

| 条件 | 实际训练 | 识别的因素 |
| --- | --- | --- |
| B0：共同 SFT 起点 | 无 RL 更新 | 初始能力；另保留旧 JSON 表示历史锚点 |
| B1：成功 rollout SFT | 用同预算收集的成功计划继续监督训练 | 更好的示范数据能否解释收益 |
| B2：终局 GRPO | 自然完整策略采样，同 root 轨迹组的终局优势作用于规划决策 | 普通长期 RL 是否已经足够 |
| B3：同候选统一 plan 优势 | 与 PRRPO 相同的分层枚举、正文候选、续跑、角色和更新机会 | 控制条件探索与额外续跑本身的收益 |
| B4：PRRPO | 同候选上分离模式优势与正文优势 | 双层信用是否有额外学习价值 |

B2 的自然采样 group 默认 4 条轨迹；候选/续跑次数与 B4 不必机械相同，但总训练计算必须可比。

B3 不能把强制得到的四个候选当作自然均匀采样的 GRPO 组。它仍按旧模式概率加权，使用与候选动作独立的状态基线 \(b(s)\)，对原子及各细化方案设 \(U_{\rm A}=\hat Q_{\rm A}-b(s)\)、\(U_i=\hat Q_i-b(s)\)，并把同一方案的统一优势同时用于其模式和正文。模式/正文的编码、裁剪与 KL 实现与 B4 一致。

\(b(s)\) 可取状态采集时独立自然后缀的终局回报；若需额外续跑，则将其费用同时计入 B3/B4 的共同采样预算。不能使用包含该候选自身回报的随意混合均值，造成未说明的概率或基线偏差。

B3 对 B4 已经是“去掉双层优势”的直接消融，不再重复训练同一个消融。若 B4 有收益，追加一个针对性比较：将根终局估值换为适用 oracle 下的局部节点估值，用于检验长期反馈的贡献。没有适用局部 oracle 的状态不编造局部真值。

### 12.2 主要指标

1. **预算内根任务成功率和首次程序成功率。** 以全部评测 root 为分母，保留无程序与失败。
2. **成功率—成本关系。** 同时报告实际训练成本和普通单分支评测成本。
3. **固定契约履约、父组合与责任重分配。** 沿用 A5 的能力隔离条件，解释整体结果。
4. **固定修复器下的结果。** 报告全 root 最终收益，并用 A7 的共同失败条件比较修复；仅比较各方法自己失败后的修复率不足以判断结构价值。
5. **粒度选择的合理性。** 在独立评测状态上重复比较 ATOMIC 与若干合法细化，观察模式选择和估计价值是否一致；把评测时搜索成本单列。
6. **责任证据覆盖。** SUPPORTED、VIOLATION、UNKNOWN 分列；局部责任已证实正确的 child 不因根失败而被标成责任错误。

分解率、树深和节点数作为辅助。少量受控任务保持外部契约与主要算法思路，只改变责任细化方式，用于区分“整体计划更好”和“粒度变化本身起作用”。

现有 8 个 DEV_MECHANISM 和 5 个 DEV_ENGINEERING 用于诊断。正式结论需要新划分的 VALIDATION/既定 HOLDOUT，保持 root/family 隔离；不能把反复看过的开发题重新称为未见任务。单 seed 结果可推进方法开发，正式稳定收益需按预定种子设置报告。

### 12.3 何时认为方法成立

工程成立的标准是：概率与实际采样对应，候选状态与预算相同，根回报能进入两层更新，冻结角色没有被更新，保存后的 adapter 能实际回接。

算法主张需要 B4 在同等成本下优于 B3，或用更少样本达到相同根任务效果，并给出模式/正文行为证据。B4 仅优于 B0 不能独自证明双层信用有效。

如果 B3 已获得全部收益，则可以保留“条件探索与完整执行比较改善任务分解”的证据，但不能把双层公式本身当成已验证贡献。

## 13. 实现时的必要验证

只验证会影响当前训练正确性和主要结论的边界，不新增通用审计系统。

| 边界 | 必要验证 |
| --- | --- |
| 模式与正文概率 | 本地真实 tokenizer；两种模式归一化；更新前旧/新比率为 1；prompt/固定模板不获得正文奖励 |
| 分层权重 | 有限离散例子的模式梯度和正文留一梯度与解析结果一致；p 接近边界与只允许 ATOMIC 时行为正确 |
| 候选来源 | 重复、非法、截断候选保留；teacher 计划只进入 SFT；不存在验证后重采直到成功 |
| 分支状态 | 相同快照和种子下未替换计划的续跑与原运行一致；预算只扣一次；分支文件互不覆盖 |
| 冻结角色 | 更新后 E_ref/R_ref 的参数和同输入前向不变；规划 adapter 确实发生更新 |
| 回报绑定 | final artifact 的分数和违规证据绑定当前版本；UNKNOWN 不当负例；私有评分不进入在线输入 |
| 端到端回接 | 小规模真实采样、一次真实 RL 更新、保存重载、正常单分支运行 |

初版设计时仅进行了代码/文献核对、本地模式分词检查及有限离散梯度验算。
后续 PR0 已完成概率/梯度单元检查、根候选重放、真实表示 SFT、冻结与重载检查，以及完整 400 次续跑的聚合验收。
PR1 已完成真实 B3/B4 更新、冻结与重载检查、54 次自然评测及完整聚合；全量 284 项测试通过。
NF4 缓存生成与完整序列评分的数值差异及本轮旧概率重算约定见 PR1 报告。
中间状态分叉和修复介入仍属于后续阶段，上表不据此视为全部完成。

## 14. 研究定位与文献依据

核心研究问题可表述为：

> 在不可弱化的上层契约下，利用完整执行结果分别估计“继续细化的价值”和“具体责任分配的价值”，使共享递归策略学会具有长期效用的责任粒度。

候选贡献有三项：责任保持的可停止递归细化建模；分层采样下概率一致的双层长期信用；生成结构对履约、组合和固定修复结果的下游价值。最关键的算法证据来自 B3/B4，而不是方法名称或公式数量。

以下仅列核对过的相关技术及其对设计的直接启示：

| 工作 | 已有内容与本设计的研究空间 |
| --- | --- |
| [DeepSeekMath / GRPO](https://arxiv.org/html/2402.03300v3) | 已有终局与过程监督的组相对策略优化；本文研究责任细化中的采样与优势组织，不以使用过程奖励作为新意 |
| [Rewarding Progress](https://arxiv.org/abs/2410.08146) | 用未来正确率的变化评价过程进展；为根终局导向的局部决策价值提供相关依据 |
| [COMA](https://arxiv.org/abs/1705.08926) | 已有边缘化某个 agent 动作的反事实基线；本文的同状态模式与条件正文比较不构成“首次反事实信用” |
| [Recursive Agent Optimization](https://arxiv.org/abs/2605.06639) | 训练递归 agent 学习委托与通信；共享递归 RL 本身已有先例，本文需突出契约约束和模式/正文信用的实证差异 |
| [ReCode](https://arxiv.org/abs/2510.23564) | 通过递归代码表示统一计划与动作、控制粒度；逐层展开本身不能独立支撑新颖性 |
| [LEMON](https://arxiv.org/abs/2605.14483) | 对可执行编排的角色、能力、依赖字段施加局部反事实修改及编辑片段反馈；本文把联合责任正文与是否细化分开，不依赖逐字段奖励 |
| [PCTD](https://arxiv.org/abs/2607.15696) | 在工具检索中研究反事实分解回报和重复分解的奖励投机；支持避免用节点/子任务数量替代任务效用 |

上述比较依据可访问的原始论文页面与摘要，足以定位本次设计；不据此宣称穷尽相关工作。原会话中未核实完整来源的 “Python is the Counterfactual” 条目，本次也未找到可核对的原始论文，故不作为论证依据。

PR0 已完成共同规划表示、冻结执行器和 50 个 TRAIN 根状态的 400 次候选续跑。
结果已定位格式支持不足、分解偏好与收益不一致，以及少量合法正文之间的下游价值差异；
PR1 的同候选更新对照已完成，但自然评测未出现完成率改善，新增任务的终局反馈主要受执行失败限制。
PR1C 已建立固定执行器可完成且合法职责划分有价值差异的 TRAIN 条件，并交付可由现有训练器加载的原始策略组。
PR1C RL 已进一步完成真实更新与新种子复测，观测到局部正文偏好变化，但自然运行未获益。
随后完成的 5 轮连续训练中，B3 首次出现 2 条配对自然净收益，B4 总体与 B0 持平、重点根退步。
等执行预算的回报估计对照进一步观察到：增加重复降低了共同候选的估计误差，并得到一条首次合法责任细化带来的自然净收益。
当前证据将经验问题推进到：如何让稀疏的完整分配比较信号稳定转化为实际责任分配和执行收益。
本轮按既定预算结束；这些 TRAIN 根上的小幅差异尚不支持双层信用的稳定优势或跨任务泛化，中间节点训练尚未启动。
