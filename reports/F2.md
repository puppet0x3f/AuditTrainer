## 关键验收

| 情况 | 观测 |
| --- | --- |
| 正确求和 / 局部前缀和函数 | PASS，实际调用 Python 函数并在宿主比较返回值 |
| 把求和写成减法 | WRONG_OUTPUT / FAIL；finish 后仍是 FAIL |
| 死循环 | TIMEOUT / FAIL，进程被终止；不是 runner ERROR |
| 候选异常、主动退出、超量输出、超内存分配 | FAIL，保留原因和受限日志 |
| 无适用 oracle、空 suite、义务覆盖不完整 | UNKNOWN；可以 finish，不产生伪 PASS |
| 同签名但语义契约不同 | suite 不可用；强制宿主调用产生 ORACLE_BINDING_MISMATCH / ERROR |
| Bubblewrap 缺失 / runner 启动异常 | ERROR；不回退到宿主执行候选 |
| 宿主文件、凭据、宿主进程、GPU、第三方 Python 包 | 沙箱访问检查未发现可见资源 |
| 宿主 loopback 监听、子进程创建、改写源码 | 连接失败、fork 被拒、源码只读；临时目录可写 |
| 预期答案隔离 | 候选扫描挂载目录不能取得宿主 oracle；只收到当前输入 |
| 私有 suite | 不在 allowed suite 中；不能由 policy 调用，离线宿主检查不修改在线轨迹 |
| 未验证提交、错误版本、自报 PASS 字段 | 拒绝，不篡改原证据 |
| 源码/契约/依赖/suite/执行配置变化 | 旧 fingerprint 不再有效；过期 PASS 不能支撑当前提交或结果 |
| 验证预算耗尽 | 拒绝多余执行，仍能依据有效证据 finish |
| 无候选时 abstain | 正常终止，功能结果为空，契约保持原样 |
| 输出正确但修改禁止变更的输入 | 功能 PASS 与责任 VIOLATION 分别记录，附具体 case 与 frame 规则 |

## 口径与完成边界

测试预期值事先手工审查；契约匹配采用完整规格相等，不把同名签名当作语义证明。
`coverage` 是 suite 登记的义务覆盖范围；遇到首个失败会停止该 suite，实际执行范围由 case 记录表示。
没有匹配项时使用保留 ID `NO_APPLICABLE_SUITE` 生成 UNKNOWN，不自动生成可信测试。

`verification_performed` 表示宿主已形成检查证据；空 suite 可为 true，但实际测试调用为 0。
`executed_cases` 记录向执行器发起的测试调用，包含启动失败尝试；`execution_seconds` 包含隔离启动开销。
finish 不重复运行 suite。过期证据保留在历史记录中，当前功能结果降为 UNKNOWN；基础设施错误保留 ERROR。

默认限制为每例 2 秒、候选进程地址空间 1024 MiB、合计输出 1 MiB、一个候选进程；
同时限制 CPU、文件大小和文件描述符。使用本机 Bubblewrap 0.4.0、libseccomp 与 Python 3.11 标准库，
不支持候选创建线程/进程或导入第三方包。当前协议是 JSON 可表达的参数及返回值，精确比较；APPS 比较适配属于 F9。

本次修正了两项结果口径：输入变更单独记责任违规；源码变化后保留历史证据，但不沿用其 PASS。
没有阻塞 F2 的工程问题。验收证明真实执行、证据绑定和原子提交已接通；LLM 能力、训练收益与正式评测未在本阶段测试。
