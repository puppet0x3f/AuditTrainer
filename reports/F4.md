# F4：责任候选、ticket、有界修复与内部计划修订

范围：**SMOKE_ONLY**。验收日期：2026-09-07。环境：Conda `audittrainer` / Python 3.11.14。

## 实现内容

- `src/audittrainer/repair.py`：模块/函数所有者、artifact/契约/consumer、证据目标三个索引；
  最多三个候选、证据约束的边界选择、一次父边界扩大、ticket、快照与无修改重放。
- `schema.py`：RepairTicket；`runtime.py`：localize、repair、授权 plan revision、LOCATE/REPAIR/PLAN 模式，
  事务期间的递归调度及全局修复/重建预算。
- 代码事务：候选目录内生成不可覆盖的新版本，明确更新授权依赖边，运行固定可见检查并核对冻结 hash，接受或回滚。
- 计划事务：保留 incoming contract，递增内部 plan version，暂存新子树并重新生成、验证和消费；失败恢复旧计划与 artifact。
- `cli.py`、FX03/FX04 fixtures：分别提供真实代码修复和计划子树重建入口。
- `tests/test_repair.py`：22 项 F4 验证；manifest 登记 FX03/FX04 并继承 FX02 的 family/SYN_FIXTURE 分区。

## 关键验收

| 情况 | 观测 |
| --- | --- |
| 只修 parent | root 恢复 PASS，child 源码和版本不变；finish 复用新证据，没有重复执行 |
| 错误定位到正确 child | 即使 child 新版本局部通过、显式重绑定完成，root 仍失败；整笔事务回滚 |
| 错误补丁 | 活跃源码、artifact、消费记录和原失败证据恢复；候选 v2 留在 attempt 目录，不进入活跃存储 |
| 修改 frozen child、任意路径、错误 base hash | 在候选写入前拒绝，仍消耗全局补丁尝试预算 |
| 未授权依赖边 | UNAUTHORIZED_REBIND；重验节点不因此获得源码修改权限 |
| 不稳定的无修改重放 | 不签发 ticket，保留两次实际结果和成本 |
| snapshot 后源码或执行配置变化 | STALE_TICKET，不接受过期授权 |
| 主 suite 通过但额外已通过 suite 回归 | 补丁被拒，验证完整固定 visible suite 集合 |
| UNKNOWN/空 suite | 不批准补丁，保持原 UNKNOWN 候选 |
| child 请求修复 | child 保持契约完成局部 v2 修复，parent 再显式消费；当时尚无 root 时不宣称 root 修复成功 |
| 自动重放耗尽验证预算 | 退出候选、恢复原程序；不重置 root 预算，可正常弃权 |
| 换 ticket 继续尝试 | 不重置三次总尝试上限 |
| 无依据扩大父边界 | 拒绝；局部尝试失败后可执行一次有证据的父计划扩大 |
| 新计划试图传入更弱 incoming contract | 严格 schema 拒绝；原契约保持不变 |
| 子树重建成功 | 新节点 ID、新 evidence、新消费记录；不继承旧 child 的 PASS |
| 子树重建失败或预算耗尽 | 恢复 v1 计划、原节点与原失败证据；尝试和已创建节点的预算不返还 |
| child 发布新版本 | 既有 consumer 证据 stale；F3 的传递版本失效检查继续通过 |

快照保存源码/计划、节点状态、可见 suite 与 runner 身份。源代码始终在 F2 的受限沙箱中执行，
预期值留在宿主；私有 suite 不进入定位、ticket、补丁选择或自动重放。

## 完成边界

F4 的两条必要事务已闭合：一条真实失败能在授权模块内修复；内部责任计划也能在冻结外部契约后重建。
失败尝试、原证据和不可覆盖的历史版本都可追踪。修复与计划重建共用三次总尝试；每节点最多一次计划修订，
自动重放使用原 root 验证预算。当前没有阻塞 F4 的工程问题。

首版采用保守的计划边界：若存在已形成的外部 consumer，必须把它纳入计划边界；
重建期间不嵌套第二个修复事务。代码事务则允许通过显式 dependency_updates 更新获授权的 consumer 绑定，
其源码仍受 frozen hash 约束。源码权限、元数据重绑定权限和重验范围分别检查。

这些结果来自人工确定的故障和 ScriptedPolicy，证明事务、证据与真实执行器已接通。
补丁通过仅说明指定可见检查下的有界干预有效，不证明唯一历史根因、全局最小边界或模型学习效果。
